# Support

## Usage questions and bugs

Search the [open issues](https://github.com/sajeetharan/cosmos-agent-starter/issues) before filing a
new report. If the problem is not already tracked, open an issue and include:

- the `create-cosmos-agent --version` output;
- your Node.js version and operating system;
- the selected starter and relevant CLI options;
- the smallest reproducible sequence of commands;
- the complete error output with credentials and customer data removed.

Generated projects can run `npx create-cosmos-agent doctor .` for configuration diagnostics and
`npx create-cosmos-agent validate .` for the full quality gate. Include those results when relevant.

## Security vulnerabilities

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) and use the
repository's private security advisory feature.

## Sensitive information

Never attach credentials, access tokens, connection strings, customer content, tenant identifiers,
or production logs. Replace sensitive values with clearly marked placeholders while preserving the
structure needed to reproduce the problem.
